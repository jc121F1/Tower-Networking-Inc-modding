# Power over Ethernet

A LuaJIT mod for Tower Networking Inc 0.12.0+. Enable it alongside `luajit-support`.

While a powered switch is connected to a device over Ethernet, the mod temporarily moves the endpoint's `Power` loads to the switch's `PowerController` using the game's `remove_local` and `add_local` methods, then updates each `Power.controller` back-reference. This includes the main logic load and auxiliary loads used by components such as status lights. In game 0.12.7, `add_local` alone adds a load to the new controller's `locals` but leaves the back-reference on the original controller. The mod refreshes both controllers, calls `Power.on()`, and sends the exposed `Power.broadcast_restored()` event to normal power listeners. When Ethernet is removed, it returns each load to its original controller and sends `Power.broadcast_lost()` while retaining power intent. This avoids duplicating or changing physical power sockets.

The prototype uses a 120W per-switch budget and a 15W per-endpoint limit. It scans every 30 game ticks and logs electrical and OS state separately. Before transfer it estimates demand from the endpoint's live load, configured fallback load, logic-controller load, and original power-controller rate, rejecting unknown or over-limit loads. It also checks combined live load after auxiliary components start. The latest game log shows that the switch's own `power_controller` and its upstream controller are the same object in this setup; choosing between them did not change power delivery. Broadcasting restoration booted the EthTapper on initial load, and the revised disconnect path allowed reconnection. The game exposes separate `Power` objects on powered lights and switches, so the mod transfers those auxiliary loads as well. The game still renders "Unpowered" in the device hover despite a live PoE-powered `Power` object, so the mod corrects that hover label to green "Powered" on the scan interval only while the endpoint has an active PoE link; it restores its prior text when power is lost. This display adjustment currently targets the English "Unpowered" label. Per-tick hover polling caused sandbox illegal-opcode faults, so the hover is now updated only every 30 game ticks with the PoE scan. The earlier run exhausted the Lua sandbox heap after repeated scans, so the mod reuses each device's Ethernet socket list within a scan, logs only meaningful scan changes, and drains wrapper allocations at the end of each game tick using the pattern established by the wireless-access mod. The game also emits `untested codeflow: controller change on power object` when the mod updates `Power.controller`.
